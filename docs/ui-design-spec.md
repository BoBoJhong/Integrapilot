# Web 介面設計規格（IntegraPilot）

## 1. 產品目標

讓使用者在單一 Web 介面完成：

1. 指定或上傳兩個專案來源
2. 執行整合評估並產出報告
3. 與 Agent 對話，形成下一步決策
4. 以選項按鈕快速產生與套用行動方案

## 2. 主要頁面

- 概覽：環境狀態、流程導覽
- 建立評估：路徑、ZIP、Git clone、執行評估
- 報告與討論：報告預覽、Agent 對話、決策選項助手

## 3. 報告與決策流程

1. 使用者載入報告
2. 點擊快速按鈕（例如：幫我想下一步）
3. 系統呼叫 options/generate 產生候選方案
4. 使用者勾選與排序方案
5. 呼叫 options/synthesize 生成綜合建議
6. 呼叫 report patch 寫入新報告版本

## 4. 互動原則

- 長操作均有 loading 狀態
- API 錯誤統一顯示 detail
- 關鍵操作以按鈕優先，避免隱藏功能
- 對話區保留 Enter 送出與 Shift+Enter 換行
